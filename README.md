# 再喝一口 · 试玩

[开始试玩](https://wangherb1.github.io/crow-water-playtest/) · 版本 0.7.0-playtest.7

一趟三瓶，共用七颗石子。小、中、大石分别涨1、2、3格水，换地点不会补满；也可以直接单独练习三个场景。

按住地上的石子，向上拖动瞄准，松手投进瓶里。
